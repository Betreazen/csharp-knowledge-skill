# csharp-knowledge

Agent Skill для разработки на C# и .NET в любой области: библиотеки и NuGet-пакеты, веб-API и микросервисы на ASP.NET Core, доступ к данным, облако и serverless, десктоп, мобильные приложения, CLI, игры, AI/ML, IoT.

Скилл даёт ИИ-агенту (Claude Code, claude.ai и другим инструментам с поддержкой формата [Agent Skills](https://agentskills.io)) три вещи:

- **библиотеку знаний** — более 900 ссылок на книги, статьи, доклады, документацию, пакеты и кодовые базы, разложенных по категориям. У каждой ссылки есть автор, год и пояснение, зачем её читать;
- **тулчейн** — обязательные и ситуативные инструменты (`dotnet format`, анализаторы Roslyn, xUnit v3, MSTest, TUnit, Microsoft.Testing.Platform, NuGet Audit, BenchmarkDotNet, dotnet-trace и другие): установка, команды, порядок шагов в CI, шаблоны `Directory.Build.props`, `.editorconfig` и `global.json`;
- **пайплайн** — тесты до кода, проверки качества, бенчмарки, базовый замер, ревью, поиск решений в библиотеке, оптимизация и повторный замер. Правка оптимизации принимается, только если бенчмарк показал выигрыш.

Состояние знаний — октябрь 2026: .NET 10 LTS и C# 14, .NET 11 и C# 15 в стадии RC. Команды проверок качества и скрипт сравнения бенчмарков проверены на .NET SDK 10.0.401. Тексты справочников на русском, названия источников — в оригинале.

## Состав

```
csharp-knowledge/
├── SKILL.md                              точка входа: куда смотреть и как работать
├── scripts/
│   └── compare-bdn.cs                    сравнение двух прогонов BenchmarkDotNet
└── references/
    ├── pipeline.md                       пайплайн разработки и оптимизации
    ├── toolchain.md                      SDK, анализаторы, тесты, CI, шаблоны конфигов
    ├── performance.md                    оптимизация: таблица «симптом → техника → источник»
    ├── idioms-patterns.md                C# 12–15, паттерны и антипаттерны, чеклист ревью
    ├── architecture.md                   структура решения, слои, DDD, CQRS, тестирование
    ├── concurrency-async-unsafe.md       async, потоки, блокировки, unsafe, P/Invoke
    ├── domains-server.md                 ASP.NET Core, данные, сообщения, облако, безопасность
    ├── domains-client.md                 десктоп, мобильные, CLI, NuGet, игры, AI/ML, IoT
    └── books.md                          книги, блоги и маршрут чтения по уровням
```

Агент загружает `SKILL.md`, когда задача касается C# или .NET. Справочники он открывает только тогда, когда нужен конкретный раздел, поэтому скилл почти не занимает контекст, пока не используется.

## Установка

**Claude Code: для всех проектов**

```bash
git clone https://github.com/Betreazen/csharp-knowledge-skill.git
cp -r csharp-knowledge-skill/csharp-knowledge ~/.claude/skills/
```

**Claude Code: для одного проекта.** Скопируйте папку `csharp-knowledge` в `.claude/skills/` в корне проекта и закоммитьте её. Тогда скилл получит вся команда.

**claude.ai.** Заархивируйте папку `csharp-knowledge` в zip и загрузите в разделе Skills настроек claude.ai. Во frontmatter только стандартные поля `name` и `description`, поэтому загрузка проходит без ошибок.

**Другие агенты (Codex, Gemini CLI, GitHub Copilot, Cursor).** Скопируйте папку в `.agents/skills/` проекта. Этот путь читают большинство инструментов с поддержкой Agent Skills.

## Использование

Скилл срабатывает сам, когда задача касается C# или .NET: написание или ревью кода, выбор пакетов и инструментов, архитектура, профилирование и оптимизация. В Claude Code его можно вызвать и явно командой `/csharp-knowledge`.

Примеры запросов:

- «Настрой для решения анализаторы, `dotnet format`, тесты на MTP и CI на GitHub Actions»
- «Профиль показывает много аллокаций в `ParseLine` — что можно сделать?»
- «Сделай ревью сервиса по чеклисту идиоматичного C# и async-кода»
- «Проведи цикл оптимизации сериализатора: бенчмарки, базовый замер, гипотезы из библиотеки, повторный замер»
- «Как разбить монолит на модули и проверить границы архитектурными тестами?»

## Пометки в справочниках

- `[устарело]` — у материала есть замена, и она указана рядом.
- `[не проверено]` — утверждение взято из одного вторичного источника; его стоит перепроверить.

Версии пакетов и SDK указаны на октябрь 2026. Со временем они устаревают, поэтому перед важными решениями сверяйтесь с nuget.org, learn.microsoft.com и release notes .NET. Учитывайте и лицензии: в 2025 году MediatR, AutoMapper, MassTransit и FluentAssertions перешли на коммерческие условия.
